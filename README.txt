======================================================================
      SAVEFROM.NET CLONE - WEBSITE SOURCE CODE & RDP PACKAGE
======================================================================

Aapki SaveFrom.net website ki saari original aur working files is folder
mein mojood hain:

1. app.py                 -> FastAPI backend + video extraction & download
2. templates/index.html   -> SaveFrom.net clone full webpage UI
3. static/css/style.css   -> SaveFrom.net exact CSS styling
4. static/js/main.js      -> Dynamic search, paste, download JavaScript
5. static/img/            -> All 19 original SaveFrom SVG icons
6. START_ON_RDP.bat       -> RDP par 24/7 chalane ke liye 1-click launcher
7. START_LOCAL.bat        -> Local computer par chalane ke liye 1-click launcher
8. requirements.txt       -> Python dependencies

----------------------------------------------------------------------
RDP PAR KAISE CHALANA HAI:
----------------------------------------------------------------------
1. Is folder ko copy kar ke RDP mein paste karein.
2. "START_ON_RDP.bat" par double click karein.
3. Script screen par aapki website ka live link dikha dega!
